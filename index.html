My current work combines geometric descriptions of cloud structure with astronomical observations. I am interested in connecting these measurements to fragmentation and the physics of star formation.

01

PRIMARY RESEARCH · 2023–PRESENT

Three-dimensional structure of nearby star-forming regions

Using the Leike et al. (2020) three-dimensional dust reconstruction, I investigate how fractal and hierarchical structure changes with gas density in nearby star-forming regions. I develop and compare perimeter–area, area–radius-of-gyration, surface–volume, and volume–radius-of-gyration analyses.

3D dust maps / Fractal geometry / Molecular cloud fragmentation

Manuscript in preparation

02

ASTRONOMICAL MACHINE LEARNING · 2026–PRESENT

Rare-object identification in large spectroscopic surveys

Developing statistical and neural-network methods for identifying rare objects in LAMOST and SDSS spectra, including white-dwarf–main-sequence binary candidates. The workflow includes data preparation, classification, and model evaluation.

SDSS / LAMOST / Spectral classification

03

SCIENTIFIC INFRASTRUCTURE · 2022–PRESENT

Calibration reference data for CSST

Contributing to the calibration reference data system for the China Space Station Telescope. My work includes reference-file recommendation rules, quality checks, structured storage and version management, and integration with data-processing pipelines.

Calibration / Reference data / Scientific software
