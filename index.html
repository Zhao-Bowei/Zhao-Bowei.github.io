My broader interest is the physical origin of the core and stellar initial mass functions. My current work starts with the gas: measuring how cloud structure changes across density levels.

MAIN PROJECT · 2023–PRESENT

How is a molecular
cloud put together?

Manuscript in preparation

Using the Leike et al. (2020) three-dimensional dust reconstruction, I investigate the fractal and hierarchical structure of nearby star-forming regions, and how these geometric descriptions vary with gas density.

I independently implemented four complementary analyses in two and three dimensions, covering both boundary geometry and the scaling of structure size.

2D / BOUNDARIESPerimeter–area
2D / SIZE SCALINGArea–radius of gyration
3D / BOUNDARIESSurface–volume
3D / SIZE SCALINGVolume–radius of gyration

I compare projected and three-dimensional measurements, examine sensitivity to analysis choices, and explore possible connections to cloud fragmentation.

SPECTROSCOPY & MACHINE LEARNING

Finding rare objects
in stellar spectra.

I develop statistical and neural-network classification workflows for LAMOST and SDSS spectra, including searches for white-dwarf–main-sequence binary candidates. My work covers data preparation, model training, and evaluation.

LAMOST · SDSS · Spectral classification

CSST & SCIENTIFIC SOFTWARE

Connecting calibration
data to science.

For the China Space Station Telescope calibration reference data system, I develop reference-file recommendation rules and quality checks, and contribute to structured storage, version management, and integration with processing pipelines.

Reference data · Quality control · Pipelines

THE NEXT QUESTION

What shapes
the structure we see?

I would like to connect three-dimensional cloud morphology with molecular-line observations of gas dynamics, turbulence, and fragmentation.

By comparing observations with star-formation simulations, I hope to investigate how physical processes shape cloud structure and, ultimately, the distribution of stellar masses.
